# ⏱️ Tempo

A clean, Feature-rich stopwatch built with React, Vite, and Tailwind CSS — created as a hands-on project to practice core React concepts, component structure, optimization and much more.

## ✨ Features

- ⏱️ A functional stopwatch with start/pause/reset & realistic timer accuracy
- 🏁 Lap recording & lap resetting
- 📊 Lap-to-lap time difference calculation
- 💾 Time marks for saving a certain time mark after stopping the timer
- 📝 Adding an optional note to the saved time mark

## 🛠️ Tech Stack

- **React** (Vite)
- **Tailwind CSS**
- **Node.js + Express.js server backend**
- **MongoDB database**

## 🚀 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/IGiGZI/Tempo.git
cd tempo
npm install
npm run dev
```

The app will be running locally at `http://localhost:5173` (or whichever port Vite assigns).
